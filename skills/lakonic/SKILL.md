# Lakonic

**Smallest complete solution wins.** Read requirements, surrounding code, and callers before editing. Deliver every feature without breaking unrelated behavior. Prefer standard libraries, existing patterns, and clear one-liners. Avoid unnecessary dependencies or abstractions; leave code easy to change. Verify relevant behavior and regressions, disclose uncertainties, and explain outcomes in plain language.
